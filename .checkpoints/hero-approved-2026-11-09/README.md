## 这一版的特征

- 细像素火焰主体：143 个 `15.12 × 17.28` 方块，四色暖色体系。
- 整体位置上移：主体与火星统一 `translate(0, -14)`，主体底部距画布下沿约 24px，顶部最暗火星在 `y 11.31`。
- 热浪：5.2s 一轮，19 行按 `0.12s` 错开，局部升温后回落。
- 每个主体方块独立浮动：`3.4–4.8s` 周期，峰值上浮约 `1.8px`，带 `0.35px` 横向偏移，相位打散。
- 四颗火星：`6.2–8.6s` 周期，向上偏左漂移约 5px，透明度在 1 → 0.72 → 0.9 之间变化。
- `prefers-reduced-motion` 下回到完全静态的版本。

## 快照与恢复

此目录保留完整 `src`、`public` 与构建配置副本；`manifest.json` 记录文件校验值。`preview-desktop.png` 是当前版本的桌面预览。

恢复时优先对照 `public/assets/fire.svg`、`src/pages/index.astro`、`src/styles/global.css` 定向恢复。保留之后对其他区域作出的独立修改；只有用户明确要求整站恢复时才覆盖完整源文件。

当前版本已通过 `npm run build` 与 `node scripts/check-build.mjs`。该目录是备份，不是线上网站的源文件。
